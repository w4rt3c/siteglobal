# TradeTech Global - Sitio Web de Trading Profesional

## 📋 Descripción

Sitio web moderno y minimalista para una empresa de trading que ofrece soluciones tecnológicas avanzadas. El sitio presenta dos servicios principales:

1. **Terminal de Noticias RSS y Tendencias**: Feed inteligente de noticias en tiempo real con análisis de sentimiento
2. **Bot de Trading Algorítmico**: Automatización 24/7 con estrategias preconfiguradas

## 🎨 Características de Diseño

- **Estética Dark Mode**: Fondo oscuro profesional (#0a0e27)

- **Efectos Glow**: Sombras luminosas en textos y bordes

## 📦 Instalación y Uso

### Opción 1: Abrir Directamente
1. Clona el repositorio
2. Abre `index.html` en tu navegador web favorito
3. ¡Listo! El sitio funciona sin necesidad de servidor

### Opción 2: Servidor Local (Recomendado)
```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (http-server)
npx http-server

# Con PHP
php -S localhost:8000
```

Luego visita `http://localhost:8000` en tu navegador.
